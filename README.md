1. Project Vision: The "Lighthouse" NavigatorA travel app that replaces static forms with a State-Aware Conversation, resulting in a living, breathing itinerary that adapts to real-world changes and deep personal history.
2. Technical Architecture & Data FlowThe app operates on a "Feedback Loop" between the user, the LLM, and live data APIs.The Persona Engine (Backend): A database (PostgreSQL + Pinecone) storing the User DNA. This tracks "Hard No's" (e.g., No cruises), "Soft Likes" (e.g., Mid-century modern design), and "Past Footprints" (imported history).The ReAct Controller (LLM): Using a model like Gemini 1.5 Pro to process chat. It doesn't just talk; it calls functions:update_state_object(): To lock in dates, budget, and group size.deep_search_agent(): To crawl live web data for events, weather, and specific destination deep-dives.The Synchronized Frontend: A split-screen interface where the LLM’s text output translates into immediate UI updates (Map markers, Timeline cards).
3. The Three-Stage Roadmap
- Phase 1: The Interview (The "Concierge" UI) Goal: Extract high-intent data without fatigue.Interface: A clean, centered chat window.Mechanism: The LLM asks 4–6 dynamic questions. As you answer "I'm traveling with my toddler," a Global Status Bar at the top updates with a 👶 icon.Result: A Travel Brief—a summary of what the LLM thinks you want. You click "Confirm" to move to discovery.
- Phase 2: The Matchmaker (The "Card" UI) Goal: Select the perfect destination.Interface: Horizontal swipe-cards.Mechanism: The LLM presents 3 destinations. Each card shows:The "Why": "Matches your preference for 20°C weather and quiet mornings."The "But": "A bit over your $200/day target, but we can save on transport."Selection: Clicking a destination triggers the Deep Search Agent, which spends ~10 seconds gathering live local data (festivals, transit strikes, new restaurant openings).
- Phase 3: The Navigator (The "Split" UI) Goal: A functional, executable itinerary.The Timeline (Left 40%): A vertical scroll of the trip. Each item is a "Live Card" (e.g., a dinner reservation card with a "Book Now" button).The Smart Map (Right 60%): A Mapbox-powered interactive map. It draws the path for the day.The "Remix" Button: A floating button. Tap it and say, "I'm too tired for the museum, find me a park nearby," and both the Timeline and Map update instantly.

5. Development Tech Stack
  Frontend: Next.js for the web dashboard; SwiftUI for the mobile "on-the-go" companion.
  Mapping: Mapbox SDK (for custom "vibe" layers and route drawing).
  Intelligence: Gemini 1.5 Pro (via API) for long-context memory of the conversation.
  Agentic Framework: LangGraph to manage the "Search -> Plan -> Review" cycle of the LLM.
6. UX Philosophy: "Invisible Personalization"The app never says "Because you are poor..." or "Because you are old...". Instead, it simply presents options that fit. If the user is a re-visitor, the UI skips the "Top 10" list and opens directly to "Neighborhood Deep-Dives" without being asked. It feels less like an app and more like a partner who just knows.
